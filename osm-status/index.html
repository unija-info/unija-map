Peraturan mudah

  • Sunting SEBELUM Ahad 08:00 UTC (16:00 MYT) → live Selasa minggu yang sama.
  • Sunting SELEPAS cutoff Ahad → tunggu Selasa minggu berikutnya.

Jadual mingguan

Masa (UTC / MYT) Peringkat Penerangan
Ahad / Sun 08:00 UTC
16:00 MYT		 Cutoff & mula build Suntikan planet OSM terkini ditarik dan kompilasi bermula. Suntingan OSM mesti sudah komit sebelum masa ini.
Selasa / Tue 08:00 UTC
16:00 MYT		 Promosi versi Build baharu ditandakan aktif dan nod produksi bertukar ke dataset baharu (sekitar 08:00–09:00 UTC).

Semakan teknikal

  1. https://tiles.openfreemap.org/planet → ambil ID build daripada .tiles[0]
  2. https://btrfs.openfreemap.com/areas/planet/${VERSION}/osm_date → tarikh snapshot OSM sebenar
  3. Jika masa suntingan < osm_date → sudah live; jika tidak → menunggu release Selasa 08:00 UTC berikutnya.

Nota: jika semakan live gagal (CORS/rangkaian), halaman ini tetap memaparkan anggaran jadual daripada jam peranti anda.
